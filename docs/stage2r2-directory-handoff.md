- 冻结提交 `0996462`；[正式 OpenAPI](knowledge-directory-import-v1.openapi.json)、[正反例与摘要向量](knowledge-directory-import-v1.examples.json)、[冻结记录](knowledge-directory-import-v1.freeze.json)为 C2 0.3.0 依据。候选文件保留原字节作为历史证据。

- 最多32个精确文件仅为一次观察集合；每次预览和确认只处理一个文件。没有批量确认、自动递归纳入、自动删除、解析、索引、Embedding、AST 或代码依赖图。
- 根句柄32位；来源和修订32位；C1根节点64位。目录项不等于知识父子节点。

## 2. A 后端已交付

复用原生登录、域所有者/租户检查、登记与来源绑定、预览存储、Document/File、原件快照、修订及 C1 固定原文读取。新建可信根配置与物理身份约束、固定列表、观察、单文件预览/字节窗口、目录回执和同键恢复，沿用 MySQL 事务与原生对象存储。

14项路由及所有请求/响应以正式 OpenAPI 为准；要求 `X-Knowledge-Contract-Version: 1.0.0` 和 `X-Knowledge-Source-Contract-Version: 0.3.0`。新路由逐次复用原生认证，返回 `Cache-Control: no-store`；原生401响应保持。原文窗口参数 `offset/length` 与 C1 的 `start_byte/end_byte` 不同。

发布、修订检查、回执持久化和预览消费处于同一域行锁事务。GET 原键/任务核查与已进入的发布事务串行化；404只能解释为不可见或未知，不能证明此前没有保存。核查不触发POST；重发必须由用户明确选择且沿用原登记/预览/摘要/键。

临时列表/观察/预览受冻结限额、TTL与域/用户配额约束。消费后立即清除暂存原文；过期目录暂存由API内清理任务清除，持久回执和已发布 C1 修订不依赖临时正文或根在线。

## 3. 运行与平台限制

- 沿用 `lfen-ragflow-poc` Compose、凭据和原卷，只替换应用二进制并增加只读可信根配置挂载；未重建凭据、删除卷或修改模型配置。
- 操作员通过私有环境变量 `LFEN_KNOWLEDGE_ROOTS_FILE` 指向可信JSON配置，字段为 roots 下的 root_id/domain_id/user_id/display_name/absolute_path/root_version/extra_exclusions。绝对路径只在服务端私有配置，不通过Web填写或返回。身份或读取策略变化必须更新版本；根句柄禁止重新绑定另一物理根。
- 当前验证路径为 **Linux容器内本地目录**。使用 openat2/no-follow/受限根、逐层精确名称和硬链接检查；网络盘、FUSE/共享盘与未验证平台均不标ready。**Windows原生、联接和Windows主机目录挂载未通过运行验收，不能宣称可用。**
- 本机合成根位于应用容器临时层，只用于本轮验证；重启容器保留，重建容器后需要重新准备合成根并使用新的根身份。持久来源和回执仍在原数据库/对象存储。正式目录持久挂载另行准备。
- 合成域和私有配置位置仅在忽略的 `.local-data/stage2r2-20261025/`，不会随Git迁移。仓库不含凭据、绝对运行根或真实资料。
