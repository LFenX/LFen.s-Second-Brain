# S2-R6 生命周期决策输入

2026-10-26。来源为“R4 原件导入客户端与界面”会话在读取[历史能力盘点](stage2r6-lifecycle-preparation.md)后的一次集中设计回报；没有重新盘点、写文件、运行测试／业务API／模型或外网。A归档这些**待确认建议**，未形成C2 0.7接口或实施。历史盘点基线38ce003中的“0.5未实现”不再描述当前；R4已交付，0.6随后获真人批准，R6仍须具体候选确认。

## 完整范围和边界

R6至少包括同域组织重分类、同登记逻辑路径移动、来源归档、来源恢复四个闭环，以及引用保留和与旧生产者竞争；不能只做归档就宣称完成。

- 重分类只改既有group_id/component_side/language，使用该来源输入投影形成／复用元信息修订；不改登记默认值、不改Feed原作者／类别，也不新增自由标签授权。
- 移动只改同登记已允许的逻辑relative_path，保持source_id/FileID／原字节；原件原名与逻辑路径分开，不能借改路径改变媒体族。网页URL／GUID／Feed身份不是文件路径，URL迁址另定。
- 归档保留绑定、当前头、Document/File、历史和保护事实，默认列表在SQL分页／计数前过滤；不以Document.status=0或清is_current实现。
- 恢复重新核验域／登记／分组／权限／策略与位置，沿用当前正文，不恢复域、根授权、成员、订阅或自动任务。

首版不含跨域／跨登记迁移、域恢复、分组树reparent、递归整树操作、真实磁盘／MinIO搬移、自动重绑定或物理GC。外部目录B缺失仍只是proposal，不能回退旧位置A或改外部磁盘。

## 核心建议，均待具体候选确认

| 决策 | 建议及原因 |
| --- | --- |
| 统一写世代 | 每源单调lifecycle_version；任何有效头／内容／分类／位置／active状态变更都增加，包含复用历史revision。命令同时核对expected_source_revision_id和expected_lifecycle_version；只在归档时增世代不能挡住正文A→B→A |
| no-op | 新键也先完整CAS与授权，确实无变化才unchanged且不增世代；不能用“已是目标状态”绕过旧CAS。数值上限／溢出拒绝须明定 |
| 原键 | 主体／域／动作隔离；原请求摘要绑定源、双expected、完整目标和confirmed。当前授权后同键同元组回固定旧回执，不再施加旧动作；异元组冲突，丢响应先GET不换键 |
| 事务与锁 | 域为最外层，原键／来源／位置／原生folder统一顺序；当前绑定、头、世代、必要原生元信息和回执一次事务。不能先普通rename再补知识绑定，不能调用物理copy/delete |
| 旧生产者栅栏 | 0.2—0.6在私有准备上下文保存观察时世代，提交／worker恢复逐项再查；不改冻结DTO／manifest。旧确认先赢则R6旧CAS拒绝，R6先赢则旧确认按旧版已知冲突语义拒绝，不能复活或追随新位置 |
| 旧pending过渡 | 没保存世代的未消费准备建议失效并要求新准备；保留已成功项／回执，不能把当前世代补造为旧观察。此影响必须进入真人确认；部署须阻止不执行新栅栏的旧二进制继续写 |
| 目标占位 | active／archived／退役位置都阻止其他源占用，同SHA不合并／覆盖／加后缀。GET不预留，提交事务和唯一性保证两源抢位仅一胜；精确UTF-8／大小写／NFC-NFD不隐式折叠 |
| 旧位置 | 移动后给原source保留退役占位，不是普通活绑定或读别名；旧位置导入不能造新Document或跳转。原source可用新CAS取回自己的退役位置；释放另定，不自动到期 |
| 固定历史 | 当前有效域授权下，归档仍可读固定C1／原件／网页历史／旧清单及回执；它们不按新位置重算。归档不等于撤权，域失效／撤权仍拒绝；源恢复不能绕过 |
| 新项目清单 | 建议新0.4发布拒绝归档或位置／分类已变化的旧基版沿用项，要求重新明确准备；不自动剔除／修正、不把原件／网页塞入0.4；旧head与非head Payload保持 |
| 保留闭包 | 全修订／节点、Commit/Item/TreeState、当前及退役绑定、原键／回执、项目全部清单、活跃／未知任务／租约、原件／网页三表示及备份。对象按后端＋桶＋key／固定版本识别，不能只看head或SHA |

建议接口分为能力、当前生命周期详情／归档列表、目标非预留检查、四类明确变更命令、固定回执ID／原键GET。小元信息操作采用“读现状→展示前后→明确POST”，不自动增加后台任务、任意JSON Patch或未定义的服务器预览。旧C1 DTO不扩字段，来源历史与当前生命周期另查。

## 十二组未来合成验收

1. 重分类异域／无效组、旧CAS no-op拒绝；合法no-op不增版。
2. 路径跨域／登记／越界／格式族及大小写、NFC/NFD规则。
3. active／archived／退役占位冲突，同SHA也不合并；原源取回退役路径须新CAS。
4. 两API／两源抢目标只一胜，无半迁移／锁死。
5. 正文A→B→A、路径A→B→A、归档→恢复三种ABA均挡住旧世代。
6. 移动／重分类和旧0.2／0.3确认双方各先赢一次；旧路径不复活／复制来源。
7. 0.4已受理任务在租约／崩溃恢复时遇变化：成功项保留，未提交旧世代失败，不自动发布完整项目。
8. 0.5 ready与归档／移动竞争，获批0.6固定选择同样校验；旧成功原键仍返回原回执。
9. 域／组／登记失效或撤权时恢复拒绝，不找替代名或恢复外部授权。
10. 成功丢响应、跨进程同键同／异元组和回放旧archive键，不重施动作／换键。
11. 改绑定／写修订／写回执阶段SQL失败全部回滚，存储故障不触发普通物理补偿。
12. 归档／移动后固定历史／旧清单／回执及原生保护保持；新发布拒绝非法沿用，撤权分页／读取不泄漏，TTL不碰持久闭包。

这些均为拟验，**未运行、未冻结、未接入**。其中完整四动作、所有写入推进世代、旧pending失效、退役占位保留、归档历史可读、新清单拒绝归档沿用须在具体候选中一次收敛再由真人确认。A继续唯一写入，消费会话只读，不据本输入启动多轮审查。
